# 2 s 지평선 + 학습한 지평선 밖 위험(RC): 강화학습 모델 정의와 검증 규칙

코드: `sim/smpc_sim/rl/risk_critic.py`, `collect_rc.py`, `train_rc.py`, `scripts/rc_model_analysis.py`, `scripts/rc_iterate.py`,
`scripts/rc_eval.py`. 가중치: `models/RC.pt`(= 아래 RC_iter1).

## 1. 문제 설정 (제약 있는 MDP)

- **기본 정책 π_base**: 2 s 지평선 반응형 시나리오 트리(`rx_mt_pf_fl_tfs_rr_ng6_nv20_nm_h10_rf10`).
  지평선 안 기회 제약 max_k Σ_b p_b r_b(k) ≤ ε(0.04)를 지키는 루트 중 비용이 가장 작은 것을 고른다.
- **결정**: 판단 틱마다 '지금 바꾸기(CHANGE_NOW)'가 기회 제약을 통과했을 때, 실제로 시작할지(a = commit) 말지.
  막으면 트리는 준비 후보(가감속 후 변경)나 기다리기를 고른다.
- **상태 s** (22 차원, `rc_features`): 자차 속도·횡 진행도·차선·차선 끝 거리/시간, 지금/목표/다음 차선의 가장 가까운
  앞·뒤차 간격과 상대 속도, 2 s 트리의 지평선 안 최대 위험 log10(peak), 정지 connector 여부.
- **비용 c** (차선 변경 하나 = 옵션 하나, 할인 없음): 그 차선 변경이 중단(복귀)·충돌·TTC < 1 s·경로 이탈로 끝나면 1, 완료면 0.

2 s 트리는 지평선 뒤(2 s 이후)를 보지 않는다. 그래서 지금 시작해도 2 s 뒤 목표 차선 뒤차가 따라붙어 중단하는
차선 변경을 막지 못한다(2 s 의 중단이 5 s 의 2.3 배). 이 '지평선 밖 위험'을 c 로 정의하고 경험에서 배운다.

## 2. 강화학습 모델: 안전 비평가(safety critic) + 제약 정책 개선

- **비평가(critic)**: Q_c^π(s, commit) = E_π[c | s, commit] = P(이 차선 변경이 나쁘게 끝남).
  - 학습 = 몬테카를로 정책 평가: 실제로 끝까지 가 본 리턴(0/1)에 회귀. 리턴이 0/1 이라 손실은 교차 엔트로피.
  - 모델: MLP 22-64-64-1(tanh) × 5 앙상블. 에피소드 단위 부트스트랩, 학습 에피소드 15 % 로 조기 종료.
    출력 = 앙상블 평균 확률(κ = 0).
- **정책 개선**: π_{k+1}(s) = π_base 에 제약 하나 추가 — Q̂_c^{(k)}(s) > θ 이면 지금 바꾸기를 막는다.
  θ 는 검증 에피소드의 J 로 고른다(J = 실패를 120 s 로 센 합류 시각 + 충돌 60 s + 중단 2 s, 작을수록 좋음).
- **반복(근사 정책 반복)**: π_k 로 다시 모은다 → 지금까지 모은 데이터 전체로 Q̂_c 를 다시 배운다 → θ 를 다시 고른다.
  - 차선 변경을 시작한 뒤의 행동(실행 중 모니터)은 반복마다 같다. 그래서 Q_c(s, commit) 는 반복 사이에 거의 변하지 않고,
    반복의 목적은 '새 정책이 바꾸기를 시작하는 상태' 쪽으로 데이터를 넓히는 것(분포 이동 보정)이다. 데이터는 모두 합쳐 쓴다.
  - 탐색: 루트 무작위 ε 0.05, 바꿀 수 있어도 0.5–3 s 기다리기 ε 0.1, RC 정책일 때 차선마다 확률 0.3 으로 RC 로 막지 않기
    (막힌 상태의 결과도 데이터에 넣어, 과하게 비관적인 추정을 고친다).
- 관련 연구: safety critic(Srinivasan 외 2020 "Learning to be Safe"), Recovery RL(Thananjeyan 외 2021),
  conservative safety critic(Bharadhwaj 외 2021). 여기서는 비평가를 모델 기반 트리의 지평선 끝 제약으로 쓴다(MPC + 학습한 끝 비용).
- TR(11-06)과 다른 점: TR 은 5 s 트리가 예측 모델로 계산한 위험을 흉내 낸다(모델 기반 증류). RC 는 시뮬레이터 NPC 가 실제로
  움직인 결과(MORAI 측정 분포, 예측 모델과 다름)에서 배운다.

## 3. 검증 규칙

**모델 검증** (`rc_model_analysis.py`, 에피소드 단위 5-fold 교차검증, 학습에 안 쓴 에피소드 예측만 평가):
1. AUC(RC) > AUC(선형 로지스틱 회귀), 차이의 95 % 부트스트랩 신뢰구간이 0 을 넘는다.
2. 주행 중(v ≥ 1 m/s) AUC ≥ 0.85, 정지 중 AUC ≥ 0.80 — 같은 상황 안에서도 가려낸다.
3. 보정 오차 ECE ≤ 0.02 — θ 를 확률로 읽을 수 있다.
4. 학습 곡선: AUC(학습 100 %) − AUC(50 %) < 0.005 이면 데이터 충분, 아니면 다음 반복에서 데이터를 늘린다.
5. 수집 정책 그대로(탐색 없음) 모은 검증 시드 데이터에서도 AUC 가 교차검증과 비슷하다(분포 이동 확인).

**주행 검증**:
- 검증 시드 6000–6299(300 회, 탐색 없음)에서 θ ∈ {0.2, 0.3, 0.5, 0.7, 0.85}(0 회차는 0.1 포함) 와 RC 없는 2 s 를
  같은 시드로 비교하고 J 최소 θ 를 고른다.
- 같은 검증 시드의 5 s 기준(`..._h25_rf10`): J 18.30, 중단 0.123, 성공 100 %.
  (rc_iterate.py 는 2 s 와만 비교하므로 5 s 짝 비교는 따로 계산한다.)
- 최종 시험: 시드 2000–2999(1000 회)에서 기존 2 s(J 19.84, 중단 0.287) · 5 s(19.17, 0.123) · 8 s(20.62, 0.144) 와 짝 비교.
- 목표: J ≤ 5 s, 중단 ≈ 5 s 수준, 충돌 0.

## 4. 결과가 나쁘면 늘린다

- 모델 검증 1–3 실패 또는 학습 곡선이 아직 오름 → 다음 반복 수집 에피소드 +3000.
- 주행 검증에서 2 s 보다 나쁘거나 5 s 에 못 미침 → 다음 반복: 데이터 +3000, 그래도 모델 지표가 정체하면 망 크기 64 → 128,
  앙상블 5 → 8. 정지 출발에서 시간 초과가 J 를 키우면 정지 상태 θ 를 따로 고른다.
- 멈춤: 시험에서 목표 달성, 또는 두 반복 연속 검증 J 개선 없음(그때까지 결과를 그대로 보고).
